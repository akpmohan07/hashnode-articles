Nature always prioritized the safest and most efficient options.

Birds lived in the nest, safe.

Humans lived inside the caves, safe.

Rats lived underground, safe.

I have written this, and you are reading; we both have space in this world!

So everything in this world needs space to live, which makes it more valuable and safer. Likewise, data requires space.

So, let's take an example: nature is building a home for animals.

**What will this space look like?**

A physical boundary representation to define how the home will look, it can look straight, like a stick, like a tree with branches, circular, like a ring, like a square, or any form.

**What can stay there?**

Different things can stay there: dogs and humans together, or just dogs?

**Who will stay where?**

The oldest dog will take the ground-floor room.

**How big is it?**

How many dogs can stay there? Can it be extended?

**How it behaves to external interaction ?**

How does a dog get in, get out, or find the one already inside that already lives there?

Answers to these questions define the structure that can store data.

Organize , store and manage the data in certain way so we can access / modify easily later.

It is an structures that stores the data..

Creating an structures to store an any data , setting boundaries between, setting behaviour, setting rules, and give a name to it.

**Questions asked for every Structures?**

How it is stored in the memory ?

How much effort we need to add , retrieve, remove from the structure ?

Benefits we can get it from the structure ?
